✨ About the Project
The Personal Portfolio Website is a responsive website developed to introduce myself and showcase my technical skills, educational background and projects.
It features a modern dark theme with neon glowing effects to create an attractive user experience.

🚀 Features
- Home section with personal introduction
- About Me section
- Skills and technologies section
- Projects showcase
- Contact section
- Interactive elements and animations
- Dark theme with neon effects
- Responsive layout for different screen sizes

🛠️ Technologies Used
- HTML5 – Website structure
- CSS3 – Styling, layouts and neon effects
- JavaScript – Interactive functionality

▶️ How to Run the Project
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code or another code editor.
3. Open "index.html" in your browser.
4. Explore the portfolio website.
